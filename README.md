# PixelScope

**A little more precise.** PixelScope is a lightweight macOS menu-bar utility for measuring anything on your screen — distances, element sizes, and spacing — with pixel-perfect snapping.

> This repository hosts **releases**, the **auto-update feed**, and the **issue tracker**. The app's source code is maintained separately.

## Download

Get the latest version from the [**Releases**](https://github.com/pixelscopeapp/pixelscope/releases/latest) page.

Requires **macOS 26** or later.

## Getting started

1. Download and move **PixelScope.app** to your Applications folder.
2. Launch it — PixelScope lives in your **menu bar** (look for the crosshair icon).
3. Grant **Screen Recording** permission when prompted (System Settings → Privacy & Security → Screen Recording). This is required to detect edges and measure other apps.
4. Click the menu-bar icon → **Measure Screen**, or use the global shortcut **⇧⌘X**.

## Licensing

PixelScope is free to try for **14 days**. After the trial, enter a license key to keep measuring:

- **Buy a license** from the in-app License screen (menu-bar icon → Options → Enter License…), which opens secure checkout on Gumroad.
- One license works on **all your Macs** — no device limit.

## Updates

PixelScope checks for updates automatically and can install them for you. You can also check manually: menu-bar icon → **Options → Check for Updates…**

## Reporting issues

Found a bug or have a feature request? [**Open an issue**](https://github.com/pixelscopeapp/pixelscope/issues/new) — please include your macOS version and the PixelScope version (menu-bar icon → Options → About).
